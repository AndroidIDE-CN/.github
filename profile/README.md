# 🇨🇳 简体中文

## 👋 关于我们

欢迎来到 **AndroidIDE-CN**！

我们是一个专注于 Android 移动端开发工具及相关技术生态的开发者组织，致力于为开发者提供便捷、高效、灵活的移动编程体验。

目前，我们的开发与维护工作主要围绕 **AIDE+** 展开，持续推进项目功能完善、体验优化及相关资源维护。

## 📢 重要公告：AIDE Pro 已停止维护

> [!IMPORTANT]
> **AIDE Pro 已正式停止维护。**
>
> AIDE Pro 不再提供功能更新、问题修复及后续版本支持。
>
> 我们已将主要开发与维护工作转移至 **AIDE+**，建议所有 AIDE Pro 用户迁移至 AIDE+，以获得后续更新与改进。
>
> 🚀 **[前往 AIDE+ 项目仓库](https://github.com/AndroidIDE-CN/AIDE-Plus)**
>
> 🌐 **[访问 AIDE+ 官方网站](https://plus.androidide.cn)**

AIDE Pro 的历史版本及相关资源将作为归档内容保留，仅供参考和历史版本获取。

## 🚀 核心项目

### 📱 AIDE+ — 当前主要维护项目

**AIDE+** 是 AndroidIDE-CN 当前重点开发与维护的 Android 移动端开发工具项目。

我们致力于持续改善 Android 移动端编程体验，为开发者提供更加便捷、灵活的开发环境。

| 项目 | 说明 |
|---|---|
| [AIDE-Plus](https://github.com/AndroidIDE-CN/AIDE-Plus) | AIDE+ 项目资源与版本发布 |
| [plus.androidide.cn](https://github.com/AndroidIDE-CN/plus.androidide.cn) | AIDE+ 官方网站项目 |

### 📦 AIDE Pro — 历史项目

AIDE Pro 是我们过去维护的 Android 移动端开发工具项目，目前已停止维护。

| 项目 | 说明 |
|---|---|
| [AIDE-Pro-Release](https://github.com/AndroidIDE-CN/AIDE-Pro-Release) | AIDE Pro 历史版本发布（已归档） |

| [resource](https://github.com/AndroidIDE-CN/resource) | AIDE Pro / Plus 历史资源备份 |

> [!NOTE]
> AIDE Pro 已停止开发与维护。新用户请直接使用 AIDE+，现有用户建议逐步迁移至 AIDE+。

## 🎯 我们关注的方向

# 🇬🇧 English

## 👋 About Us

Welcome to **AndroidIDE-CN**!

We are a developer organization focused on Android development tools and the mobile development ecosystem.

Our mission is to make Android development more accessible, efficient, and flexible by providing practical tools, resources, and an improved mobile programming experience.

Currently, our primary development and maintenance efforts are focused on **AIDE+**, including ongoing improvements, feature development, and project resources.

## 📢 Important Notice: AIDE Pro Discontinued

> [!IMPORTANT]
> **AIDE Pro has been officially discontinued and is no longer maintained.**
>
> AIDE Pro will no longer receive feature updates, bug fixes, or future version support.
>
> Our development and maintenance efforts have moved to **AIDE+**.
>
> We strongly recommend that all AIDE Pro users migrate to AIDE+ to receive future updates and improvements.
>
> 🚀 **[Visit the AIDE+ GitHub Repository](https://github.com/AndroidIDE-CN/AIDE-Plus)**
>
> 🌐 **[Visit the AIDE+ Official Website](https://plus.androidide.cn)**

Historical AIDE Pro releases and related resources will remain available for archival and reference purposes.

## 🚀 Featured Projects

### 📱 AIDE+ — Actively Maintained

**AIDE+** is the primary Android development tool project currently maintained by AndroidIDE-CN.

We aim to continuously improve the mobile development experience by enhancing functionality, usability, and the overall development environment.

| Project | Description |
|---|---|
| [AIDE-Plus](https://github.com/AndroidIDE-CN/AIDE-Plus) | AIDE+ resources and version releases |
| [plus.androidide.cn](https://github.com/AndroidIDE-CN/plus.androidide.cn) | AIDE+ official website project |

### 📦 AIDE Pro — Legacy Project

AIDE Pro is a legacy Android development tool project that has reached the end of its maintenance lifecycle.

| Project | Description |
|---|---|
| [AIDE-Pro-Release](https://github.com/AndroidIDE-CN/AIDE-Pro-Release) | Historical AIDE Pro releases (archived) |
| [pro.androidide.cn](https://github.com/AndroidIDE-CN/pro.androidide.cn) | AIDE Pro website project |
| [resource](https://github.com/AndroidIDE-CN/resource) | Archived AIDE Pro / Plus resources |

> [!NOTE]
> AIDE Pro is no longer actively developed or maintained. New users should use AIDE+, and existing users are encouraged to migrate.
